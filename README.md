One line, 120 characters — the boss who takes "drowning in work" literally.

`main.ts` writes the single 120-character line to `/output/entry.txt`:

> I told my boss I was drowning in work, so he enrolled me in “Swimming Lessons” for 8 a.m. Monday — attendance mandatory.

Offline and deterministic: no network, no clock, no randomness. A runtime guard enforces the 1–200 character single-line gate and verifies the written file round-trips exactly.

Run it with Node 22+:

```
node main.ts
```
